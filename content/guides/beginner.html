道具をそろえよう

作業台は、スタイロフォームで作った簡単なものを使います。ケースは、持ち帰るときだけでなく乾燥・保管にも使います。

表面の水気を取るために、キッチンペーパーなど水を吸う紙も用意します。

会場では、まず平らな作業台を使います。体高によってくぼみが必要なときは、カッターを使う前にスタッフまたは付き添いの大人に相談します。家庭で作る場合は、大人がカッターを扱います。

このガイドでは、甲虫の体に針を刺しません。昆虫針は先がとがっているので、大人と一緒に扱います。

甲虫を用意しよう

道具がそろったら、作る甲虫を用意します。乾燥して硬くなった甲虫は、形を整える前に、水分を与えて関節を動かせる状態にします。この作業を「軟化（なんか）」といいます。

会場では、軟化済みの甲虫を使います。スタッフから受け取ったら、次の「水気を取ろう」へ進めます。

家で作るときの、甲虫の準備

乾燥した甲虫から作る場合は、状態に合う方法で軟化します。硬い足や触角を、力で動かして確かめる必要はありません。

すでに動かせる状態の甲虫や、今の姿のまま残す甲虫には、軟化は不要です。

軟化の方法と、動かせる状態の確かめ方 →

軟化ができたら、このページの「水気を取ろう」に戻って作業を続けます。

採った場所・日付・人の名前が分かるときは、忘れないうちにメモしておきましょう。虫と一緒にもらったラベルも残しておきます。

水気を取ろう

甲虫に水滴が残っているときは、用意した紙の上に置いて、表面の水気を紙に吸わせます。からだを強く押さえたり、こすったりせず、脚や触角が紙に引っ掛からないように持ち上げましょう。

水滴が見えなければ、そのまま次の手順へ進めます。

からだの高さを見よう

クワガタを横から見ると、からだに厚みがあります。この厚みを「体高（たいこう）」といいます。作業台に置いたとき、からだが高くて脚を整えにくい場合があります。

脚を整えにくいほどからだが高い場合は、押し付けて高さを合わせず、作業台にからだが収まる浅いくぼみを作ります。問題なく置ける場合は、そのまま次へ進みましょう。

必要なら、くぼみを作ろう

位置に印を付ける

平らな作業台で脚を整えにくいときだけ、くぼみを作ります。不要な場合は、この手順を飛ばして次へ進みましょう。

クワガタを作業台に仮置きし、からだの下が入る範囲を見ます。写真のように、昆虫針でスタイロフォームに線を引いて、くぼみを作る位置の目安を付けます。

{{ media-recess-mark }}

くぼみを作る

カッターを使うときは、クワガタをいったん外します。印を付けた範囲を少しずつ削り、くぼみができたら仮置きして、からだが安定し、脚を整えやすい高さか確かめます。

会場では、まず平らな作業台で作業を始めます。くぼみが必要な場合は、スタッフまたは付き添いの大人に相談してください。家庭で作る場合は、カッターを大人が扱ってくぼみを作ります。

閉じた脚をひろげよう

このクワガタでは、作業台に置く前に六本の脚を外へひろげました。閉じた脚がからだの下に残ると、置いたあとで動かしにくくなるためです。

写真のようにおなか側から脚の向きを見て、動かせる範囲で開きます。ここで脚の形を決める必要はありません。硬くて動かない脚は、軟化の状態を確かめましょう。

脚の位置を整えよう

足の位置を整えることを「展足（てんそく）」といいます。どんな姿にしたいか考えながら、少しずつ整えましょう。

まず、脚の太い部分の腿節（たいせつ）と、その先の脛節（けいせつ）の向きを整えます。六本の脚が重ならず、形が見える位置を考えましょう。

この作例では左前脚から始め、時計回りか反時計回りに順番に整えています。始める脚や回る向きは自由です。

{{ media-legs }}

関節の近くを見てみよう

拡大写真では、脚と、脚の位置を支える作業台の針が見えます。ピンセットで脚先を引っ張らず、動かしたい関節に近い部分をそっと支えます。針は甲虫に刺さず、作業台に立てます。

からだまで動いたり、脚がしなるのに関節が動かなかったりするときは、力を加えるのを止めて、軟化の状態を確かめます。

跗節を整えよう

腿節と脛節の向きが決まったら、脚の先にある跗節（ふせつ）を整えます。跗節は脛節の先から爪までの間にある、細かく分かれた部分です。

この作例では後脚の跗節から始めています。跗節を整える順番も自由です。一本ずつ脚先の向きを見て、触角との重なりも確かめながら、作業台に立てた針で位置を保ちます。

{{ step-dry }}

形を整えたら、乾かそう

形を整えたら、針やバンドを外さず、作業台ごとケースに入れて乾かします。

乾かすときの注意点

  • ケースのふたを開けて、湿気がこもらないようにする
  • 直射日光を避ける
  • なるべく涼しく、風通しのよい場所に置く
  • ケースには乾燥剤を一緒に入れる

ふたを開けるときは、小さな虫やほこりが入りにくく、作業台が倒れない場所に置きます。乾燥剤は製品の案内に合わせて交換します。

{{ media-drying }}

どのくらい乾かす？

乾燥は数日で終わるとは限らず、数週間から1か月以上かかることもあります。甲虫の大きさ、水分の残り方、部屋の湿度で変わります。表面が乾いたことだけでは、中まで乾いたかは分かりません。

会場で作った人は、その甲虫に合わせた乾燥期間をスタッフに確認してください。

乾かしたあとの固定と保管

十分な期間をかけて乾かしてから、固定を外します。日数だけで決めず、初めて扱う種類は、制作経験のある人に乾燥期間や状態を確認してもらいましょう。乾いたか調べるために、足を曲げたり腹を押したりはしません。

針やバンドを外すときは大人と一緒に行います。足や触角を引っ掛けないように一つずつ外し、バンドが体に貼り付いているときは、引っ張らずに外し方を確認してください。

固定を外す途中で足などの位置が変わるなら、まだ形が安定していません。いったん外すのを止め、支えた状態で乾燥を続けます。形が保てても、それだけで体の中まで乾いたとは判断できません。

乾燥後は、ほこりや虫が入りにくい、ふたの閉まるケースで保管します。乾かしている間の通気とは分けて考えましょう。ときどき、カビや小さな虫、食べかすのような粉が出ていないか見ます。異変があれば、ほかの標本とケースを分けて対処を相談します。

乾かしている途中で、形を直したいときは？

まだ関節を動かせる状態なら、直せる場合があります。硬くなっていたら、力で動かさず、必要に応じてもう一度軟化します。作ってからの日数だけでは判断できません。

ラベルを添えよう

はじめに残したメモを、小さな紙に書き写します。ラベルは、乾かしている間に用意しても構いません。

採ったときの記録
採った場所・採った日・採った人
作ったときの記録

作った日と採った日は別の情報です。分からないところは想像で埋めず、「不明」とするか空けておきます。もともと付いていたラベルは、書き換えずに一緒に残します。

{{ media-label }}

ラベルはケースの中で、どの標本のものか分かる位置に置きます。複数の標本を入れるときは、標本ごとに区画を分けるなどして、ラベルと取り違えないようにしましょう。

記録がない標本でも姿や形は楽しめますが、採った場所や日付は、標本だけでは分かりません。

{{ questions-label }}

写真だけでもいい？

写真にも残せます。標本なら、あとから向きを変えたり、気になる部分を大きくして見たりできます。写真と標本の両方を残してもいいですね。

足が取れたら、失敗？

足が取れても、標本を楽しんだり、残っている部分を観察したりできます。取れた足も捨てずに、どの標本のものか分かるように残しておきましょう。

どうして固定したまま乾かすの？

形を整えた直後は、まだ足や触角が動くためです。乾いて形が安定するまで、針やバンドで支えておきます。

困ったときは

  • 足や触角が動かない：軟化できたかを確認する
  • 乾かし方や固定を外す時期：乾燥・保管を確認する
  • 置き方やバンドの使い方：会場ではスタッフに、家では一緒に作る大人や制作経験のある人に確認する
